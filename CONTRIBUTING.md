# Contributing to Clerk

## Setup

```bash
git clone https://github.com/Anant-Madhok231/clerk-ai.git
cd clerk-ai
npm install
npm run dev
```

`npm install` rebuilds `better-sqlite3` for Electron's Node ABI automatically (see the root `postinstall` script). If native module errors show up after switching branches or Node versions, re-run `npm install`.

## Before opening a PR

```bash
npm run lint
npm run typecheck
npm test                              # logic that doesn't touch SQLite
npm run test -w apps/desktop
npm run test:db -w apps/desktop        # db-backed tests, run through Electron's Node runtime
npm run build
```

All of these must pass. Don't skip hooks or suppress failures to get a green run — fix the underlying issue.

## Code style

- TypeScript strict mode. Prefer explicit domain names (`gmailSync.ts`, `situationRepository.ts`) over generic ones (`utils.ts`, `helpers.ts`).
- Comments explain *why*, not *what* — skip a comment if the code already reads clearly.
- No AI-boilerplate comments, no "Generated by Claude"-style markers in source.
- Don't add abstraction ahead of a second real use case. A `packages/*` split, a new interface, or a shared helper should follow actual duplication, not anticipate it.
- Every model classification response must be validated with Zod before it touches persistence or the database — see `apps/desktop/src/main/ai/AIProvider.ts`.

## Tests

- Domain/pure-logic tests: plain `*.test.ts`, run via `vitest run`.
- Anything touching `better-sqlite3` (directly or via Drizzle): name it `*.db.test.ts` — the two Vitest configs (`vitest.config.ts` / `vitest.db.config.ts`) split on that suffix, not on directory, specifically so this can't drift out of sync again.
- New matching/reconciliation behavior needs a test that exercises the real pipeline (`processSourceItem`), not a mocked shortcut — this is the part of the codebase most worth protecting from regressions.

## Commits

Real commits for real milestones. No fabricated history, no placeholder/WIP commits meant to pad the log.
